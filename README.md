# 為替レート PWA 統合版

GitHub Pages向けiPhone PWA試作版です。

## 初期起動コード
`0000` → `÷` → `＝` の順に入力します。アプリ内の設定変更後は新しいコードを使います。

## 主な内容
- iPhone向け表示、画面下部固定ナビゲーション
- 設定画面を開く際のアプリ起動コード認証
- 起動コード変更（現在コードの確認が必要）
- 秘密フォルダ専用パスワード、AES-GCM暗号化
- 秘密ファイルを通常一覧から分離
- iOSのタップ拡大・入力欄ズームを抑える表示設定

## 重要な制限
- 為替レートはデモ値で、リアルタイムAPIには接続していません。
- URL取得はCORS等で許可された直接動画・画像URLのみです。一般的な動画サイトのページ解析は実装していません。
- PWAの保存容量・保持はiOSが管理し、80GBを保証できません。大切なファイルは別途バックアップしてください。
- 暗号化とパスワード変更はブラウザ内処理です。実機でテストファイルを使い、解除・変更・復元を確認してから本データを入れてください。パスワードを忘れると復元できません。
- iPhone実機での動作確認は未実施です。
