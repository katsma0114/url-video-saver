# 為替レート PWA v0.6

## 今回の更新
- 2〜8桁の起動コードを設定し、為替画面で「数字→÷→＝」を入力してアプリ画面へ移動
- 通常ファイルをiPhoneのファイル選択からIndexedDBへ保存
- マイコレクションで一覧・名前順/日付順表示
- 秘密フォルダへ移動する際にWeb Crypto AES-GCMでファイル本体を暗号化
- 秘密フォルダからの復号表示・通常一覧への復帰
- アプリ起動コードと秘密フォルダ用パスワードは別管理

## 大切な制限
- 秘密フォルダのパスワードはこの試作ではセッション中に保持されます。再起動後のパスワード検証・salt/verifier管理など、製品レベルの認証強化は次工程です。
- ブラウザ内保存はiOSの容量制限・データ消去等の影響を受けます。80GB保管を保証しません。
- リアルタイム為替レートAPIは未接続です。表示レートはデモ値です。
- URL検索は直接の動画/画像ファイルURLでブラウザ取得が許可された場合のみ。Gofile等のページ解析は未実装です。
- 重要ファイルの唯一の保管先として使わないでください。

HTTPS環境に配置し、iPhone Safariの共有メニューから「ホーム画面に追加」でPWAとして確認できます。
