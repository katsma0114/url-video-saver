# 為替レート PWA v0.8

iPhone向けGitHub Pages用PWA試作版です。

## v0.8変更点
- 為替画面右上の設定入口を、小さな「…」から押しやすい「設定」ボタンに変更
- 設定ボタンを押すと起動コード設定欄へスクロールして表示
- 起動コードの桁数に5桁を追加

## 公開
GitHub Pagesで `main` ブランチのルート（/(root)）を公開してください。

## 注意
為替レートはデモ値です。URL検索はCORS等の制限を受けます。iOS PWAの保存容量は保証されません。秘密フォルダ機能は試作段階のため、重要なデータの保管には使用しないでください。
