# 為替レート PWA 統合版

GitHub Pages用のiPhone向けPWA試作版です。

- 初期起動コード：0000（設定後は変更したコード）
- 起動コード変更：現在のコードを確認してから変更
- 設定画面：起動コード入力後に表示
- 秘密フォルダ：別パスワード、AES-GCM暗号化、通常一覧から分離
- 秘密フォルダのパスワード変更：保存済み暗号化ファイルを新しいパスワードで再暗号化
- 下部ナビゲーション：固定配置・iPhoneセーフエリア対応
- IndexedDBの既存データベース名と起動コード保存キーは維持

注意：為替レートはデモ値です。URL取得はCORS等のブラウザ制約を受けます。iOS PWAの保存容量・保持は保証されません。実データ投入前に、必ずテストファイルで保存・暗号化・復号・パスワード変更を確認してください。秘密フォルダは現時点で専門的なセキュリティ監査を受けた製品ではありません。
