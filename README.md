# 為替レート PWA v0.10

iPhone向けGitHub Pages用PWA試作版です。

## 起動方法
- 初期コードは `0000` です。
- 為替画面で `0` → `0` → `0` → `0` → `÷` → `＝` の順に入力するとアプリが開きます。
- 起動コードの変更は、アプリ内の設定画面から行います。
- 変更時は現在の起動コードの入力が必要です。
- 為替画面には設定ボタンを表示しません。

## 注意
- 為替レートはデモ値です。
- URL検索は、ブラウザから直接取得できる動画・画像ファイルに限られます。ページ解析やDRM回避は行いません。
- iOSのPWA保存容量・保持期間はOS管理であり、大容量保存を保証しません。
- 秘密フォルダ機能は試作段階です。重要・機密ファイルの保管には使用しないでください。
