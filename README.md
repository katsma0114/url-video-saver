# 為替レート PWA v0.7

GitHub Pages向けのiPhone用PWA試作版です。

## 初回起動
1. 為替画面で「÷」を押します。
2. 続けて「＝」を押すと、初回設定画面が開きます。
3. 2〜8桁のアプリ起動コードを設定して保存します。
4. 次回以降は、為替画面で設定した数字 → ÷ → ＝ の順に入力します。

秘密フォルダのパスワードはアプリ起動コードとは別です。

## 注意
為替レートはデモ値です。URL検索はブラウザから直接取得できるファイルURLのみ対象で、サイトページ解析には未対応です。iOSのPWA保存容量・保持は保証されません。重要なデータの保管には使用しないでください。
